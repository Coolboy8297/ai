Compatibility notes

Vanilla runs without mods or plugins. Paper is built for plugins. Fabric, Forge and NeoForge are mod loaders; the game version and mod versions must match.

The version list is a starter list, not a live manifest. Before deployment, the backend should validate that the selected software/version combination actually exists.
Resource limits are estimates. A free host may impose lower RAM, storage, player, or uptime limits.
