01 / PLAY HALO

Halo: Combat Evolved — browser runtime

The game runs through the independently hosted Halo CE Web client below. When it loads, use its Choose XISO button and select your own .xiso.iso file. The file picker must be used inside the game client because browsers do not let this GitHub page pass a local file directly into another website.

Your ISO is selected by the external game client, not uploaded to this GitHub repository. If the embedded game stays blank or refuses to load, use “Open game in its own tab” below.

02 / ONLINE PLAY

Play with friends

The embedded client has its own online multiplayer interface. GitHub Pages hosts this launcher only; the game runtime and multiplayer services are hosted separately.

  • Load your ISO using the embedded client’s “Choose XISO” button.
  • Wait for the game to finish loading.
  • Use the client’s online multiplayer menu to create or join an invite room.
